# Delegacia RPG

Jogo Android nativo em Java, renderizado diretamente com `SurfaceView` e `Canvas`.
Compatível com orientações vertical e horizontal; no modo horizontal, os três cômodos aparecem lado a lado.
Os ambientes têm pisos em perspectiva e interiores próprios para recepção, arsenal e celas, com detalhes de desgaste.

## Como jogar

- Segure as setas na tela para mover o policial.
- Toque nos cômodos para reformá-los quando tiver sucata e moral.
- Patrulhe, investigue, avance de fase e interaja com os NPCs.
- Aproxime-se do quadro Calibre 12 para liberar o bônus secreto.

## Executar

Abra este projeto no Android Studio e execute a configuracao `app` em um emulador ou dispositivo Android (API 23 ou superior). Para gerar o APK debug, execute `./gradlew assembleDebug`.
